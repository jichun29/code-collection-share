> 部分脚本可能存在残留凭证缓存，使用前请自行检查默认值并清理缓存。

## 如何使用

1. 进入 `code/可用/` 挑一个脚本；
2. 在青龙面板新建任务，命令填 `task <脚本相对路径>`；
3. 需要环境变量的脚本，按脚本头部注释配置。
