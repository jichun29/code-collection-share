# code-collection-share

> **脚本收集备份仓库**（非原创，仅作个人备份与整理）

## ⚠️ 关于本仓库

本仓库**不是脚本作者**，只是一个**收集备份**仓库。仓库内所有脚本均**来自网络公开分享**，版权归各自原作者所有。

| 来源 | 说明 |
|---|---|
| **L0NE-6/code-collection-share** | 上游原仓库（本仓库为其 fork） |
| **SuperNaiBA/YYB-GO-Script** | yyb-go 系列小程序脚本 |
| **lcmovie/YYB-GO-Script** | yyb-go 系列小程序脚本 |
| 其他公开分享 | 网络收集，未能一一追溯 |

- 本仓库**仅做备份与状态整理**（标注哪些实测可用），**不修改脚本内容逻辑**；
- 上传前已做**脱敏处理**（手机号 / 邮箱 / 内网 IP / 私钥 / Token 均已清除）；
- **使用风险自负**，与本仓库维护者无关。

## 如何使用

1. 进入 `code/可用/` 挑一个脚本；
2. 在青龙面板新建任务，命令填 `task <脚本相对路径>`；
3. 需要环境变量的脚本，按脚本头部注释配置。
